1. Rate Limiting Configuration

All expensive endpoints are now protected against abuse with tiered rate limits calibrated for the demo workflow.

Endpoint Category Limit Window Target
General API 100 15 minutes All /api endpoints (except health)
AI Investigation 5 15 minutes POST /api/ai/investigate/:exceptionId
RAG Search 10 5 minutes POST /api/rag/search
RAG Ingestion 2 1 hour POST /api/rag/ingest
CSV Upload 5 15 minutes POST /api/upload
Reconciliation 3 15 minutes POST /api/reconciliation/run/:runId

IPv6 Safety: All limiters use default IP-based key generation. Custom key generators that used req.ip directly were removed to avoid ERR_ERL_KEY_GEN_IPV6 errors.

2. Request Validation Middleware

The validation.js middleware provides UUID validation for route parameters, preventing unnecessary database queries for malformed IDs.

// Middleware applied to reconciliation routes
router.post('/reconciliation/run/:runId', reconciliationLimiter, validateRunId, ...)

// UUID format validation prevents PGRST116 errors
// before querying Supabase

Available Validators:

  • validateRunId — UUID validation for reconciliation run IDs
  • validateExceptionId — UUID validation for exception IDs
  • validateBody(schema) — Zod schema validation for request bodies
  • sanitizeInput(str) — String sanitization helper

3. LLM Output Validation

Groq LLM responses are now validated against a strict Zod schema before database persistence.

import { aiInvestigationSchema, validateAIInvestigation } from '../middleware/llmValidation.js';

// Schema enforces structure and required fields
const schema = z.object({
  summary: z.string().min(10).max(1000),
  evidence: z.array(z.string()).min(1).max(20),
  reasoning: z.string().min(20).max(2000),
  recommended_action: z.string().min(10).max(500),
  confidence: z.enum(['high', 'medium', 'low']),
  sources_used: z.array(z.object({...})).optional(),
  status: z.enum(['EXPLAINED', 'UNRESOLVED', 'MANUAL_REVIEW']),
});

Duplicate Investigation Prevention: The AI route now checks for existing investigations within 1 hour before triggering expensive Groq calls. Cached results are returned with a cached: true flag.
